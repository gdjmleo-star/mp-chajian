# MP 自定义插件仓库

## 使用方法

在 MoviePilot WebUI → 插件市场 → 添加仓库，填入：

```
https://github.com/gdjmleo-star/mp-chajian
```

## 插件列表

### CustomMediaCat - 自定义媒体分类 v7.8

- 电视剧按 QB 源文件名关键词（NF/HBO/MAX/DSNP/ATVP/HULU/AMZN）分类到对应专区
- 电影按杜比视界关键词归入「杜比视界电影」
- 电影按 4K 关键词（2160p/4K/UHD）升级到对应 4K 目录
- 支持 WebUI 可视化配置，规则全部可自定义
